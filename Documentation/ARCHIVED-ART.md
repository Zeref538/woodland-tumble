# Original artwork and historical screenshots

Original sprite sheets were verified byte-for-byte against the separate [Woodland-Scouts sources](https://github.com/Zeref538/Woodland-Scouts/tree/main/tumble/sources) before duplicate copies were removed from this game's current tree. Runtime sprites, Unity metadata, scenes, packages and settings remain in the game repository.

Older screenshots remain available in the [v8.0.0 documentation tree](https://github.com/Zeref538/woodland-tumble/tree/v8.0.0/Documentation) and its [full Unity archive](https://github.com/Zeref538/woodland-tumble/releases/tag/v8.0.0). Git history has not been rewritten. Old manifests may reference those historical source paths.

Use the latest project ZIP or clone with --depth 1 to avoid downloading historical files. A normal full-history clone still contains the older large objects.
