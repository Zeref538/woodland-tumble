# GitHub repository

Public project: https://github.com/Zeref538/woodland-tumble

Clone it on your own computer with:

```sh
git clone https://github.com/Zeref538/woodland-tumble.git
```

Open the cloned folder in Unity 6000.5.10f1 and open `Assets/Scenes/WoodlandTumble.unity`.

Commit `Assets`, `Packages` and `ProjectSettings` together, including every `.meta` file. The included `.gitignore` excludes Unity caches, logs, builds and local staging files.

## School/lab computer cleanup

After the initial upload, the GitHub CLI account is signed out, the associated CLI Git credential helpers are removed, and the user-installed CLI is uninstalled from this computer. The local Unity project and public Git history stay available. A public clone URL does not contain login credentials.

If GitHub was also opened in a browser, sign out using the profile menu and remove any saved GitHub password for your account. CLI logout does not sign out a browser. From your own trusted device, you can also review GitHub Settings > Sessions and Settings > Applications > Authorized OAuth Apps.

CLI reference: https://cli.github.com/manual/gh_auth_logout
